Responsiveness tips

  • Try USB connection if you prefer a wired setup; compare feel in the same game.
  • Keep vibration off if you prefer less controller feedback.
  • Choose a stick response curve that feels controllable, not just the fastest.
  • Very low deadzones can make small stick movements more noticeable; raise them if the aim feels unstable.

Keyboard setup

Keyboard

Compatibility and feel

Check whether your game supports keyboard and mouse on PS5. Keyboard software features configured on a PC may not transfer to the console.

  • Use a stable USB connection where supported.
  • Choose keybinds that are comfortable and easy to repeat.
  • Do not assume a keyboard's advertised polling rate is used by every PS5 game.
Display response · personalised setup

Monitor

Find your best supported resolution

Choose the highest resolution your screen and PS5 both support. This page cannot detect your monitor automatically, so check the PS5 Video Output Information or your screen's manual.

Recommended: select 1440p on the PS5 if 1440p is shown as supported. If 4K is supported and preferred, you can select 2160p instead.

If 1440p is not supported, choose 1080p. If 1080p is not supported, choose 720p. Do not choose a mode marked unsupported.

Refresh rate

If your screen and game support 120Hz, enable 120Hz output on the PS5. Otherwise use the highest supported refresh rate.

Reduce display processing delay

  • Enable Game Mode or the monitor's low-latency mode.
  • Disable extra picture processing if it adds delay.
  • Use a suitable HDMI input and cable for the display's supported features.

The highest resolution is not automatically the lowest-latency option in every game. A game's performance mode and supported frame rate also matter.

Online connection

Network

Reduce avoidable online lag

  • Use Ethernet if practical; otherwise use a strong Wi‑Fi signal.
  • Pause large downloads and uploads while playing.
  • Run the PS5 connection test and note download, upload and NAT results.
  • Remember: ping and server distance affect online response, not local controller input delay.
Console settings

PS5

Supported system checks

  • Settings → Screen and Video → Video Output: review resolution, 120 Hz output and VRR where supported.
  • Settings → Accessories → Controller: review available controller options.
  • Keep system software and games updated.
  • Use each game's own performance or graphics mode when available.
